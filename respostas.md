# Respostas das atividades

## Atividade 1
**Resposta:** O arquivo index.html será responsável pela estrutura e pelo conteúdo da página. O arquivo style.css será responsável pela aparência e pelo layout.

## Atividade 2
**Resposta:** A declaração `<!DOCTYPE html>` deve aparecer no início do documento para indicar que ele utiliza HTML5[cite: 1].

## Atividade 3
**Resposta:** A tag `<title>` deve ser utilizada para definir o título exibido na aba do navegador[cite: 1].

## Atividade 4
**Resposta:** A tag `<h1>` representa o título principal e a tag `<p>` representa um parágrafo[cite: 1].

## Atividade 5
**Resposta:** A tag `<section>` deve ser utilizada para representar uma seção temática de conteúdo[cite: 1].

## Atividade 6
**Resposta:** O elemento `<nav>` agrupa os links de navegação, e o atributo `href` define o destino do link[cite: 1].

## Atividade 7
**Resposta:** O atributo `id` identifica unicamente uma seção, e o valor no `href` deve ser escrito com `#` seguido do nome do id (ex: `#sobre`)[cite: 1].

## Atividade 8
**Resposta:** A tag `<img>` insere a imagem, e o atributo `src` define o caminho do arquivo[cite: 1].

## Atividade 9
**Resposta:** As tags `<figure>` e `<figcaption>` agrupam a imagem e sua legenda[cite: 1].

## Atividade 10
**Resposta:** O atributo `href` define o endereço de destino de um link[cite: 1].

## Atividade 11
**Resposta:** Um link interno direciona para outro arquivo do próprio projeto, enquanto o link externo direciona para um endereço fora dele[cite: 1].

## Atividade 12
**Resposta:** `<table>` representa a tabela, `<tr>` representa uma linha, `<th>` é a célula de cabeçalho e `<td>` é a célula de dados comum[cite: 1].

## Atividade 13
**Resposta:** Utiliza-se o prefixo `mailto:` no atributo `href`[cite: 1].

## Atividade 14
**Resposta:** O elemento `<footer>` representa o rodapé de um documento[cite: 1].

## Atividade 15
**Resposta:** A tag `<link>` deve ser utilizada para relacionar o documento a uma folha de estilos externa, utilizando o atributo `rel="stylesheet"`[cite: 1].

## Atividade 16
**Resposta:** A propriedade `font-family` define a família da fonte[cite: 1].

## Atividade 17
**Resposta:** A propriedade `color` define a cor do texto e a propriedade `text-align` define o alinhamento[cite: 1].

## Atividade 18
**Resposta:** Podemos selecionar dois ou mais elementos diferentes em uma mesma regra CSS separando-os por vírgula (`h2, h3`)[cite: 1].

## Atividade 19
**Resposta:** O símbolo de ponto (`.`) é utilizado no CSS para selecionar uma classe, e o atributo HTML `class` associa o elemento a ela[cite: 1].

## Atividade 20
**Resposta:** O símbolo de cerquilha (`#`) deve ser utilizado para selecionar um elemento pelo seu ID[cite: 1].

## Atividade 21
**Resposta:** A propriedade `width` define a largura e o valor `auto` ajusta automaticamente a altura[cite: 1].

## Atividade 22
**Resposta:** A propriedade `padding` define o espaçamento interno de um elemento[cite: 1].

## Atividade 23
**Resposta:** A propriedade `margin` define o espaçamento externo, e a expressão `margin: 0 auto` centraliza o elemento horizontalmente[cite: 1].

## Atividade 24
**Resposta:** A propriedade `float` com o valor `left` permite que o elemento flutue para a esquerda[cite: 1].

## Atividade 25
**Resposta:** A propriedade `width` define a largura, `border-collapse` unifica as bordas e a propriedade `border` define a borda das células[cite: 1].

## Atividade 26
**Resposta:** A propriedade `text-decoration` com o valor `none` remove o sublinhado dos links[cite: 1].

## Atividade 27
**Resposta:** O rodapé foi estilizado utilizando `background-color`, `padding` e `text-align: center;`[cite: 1].
